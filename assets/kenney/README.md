All included assets are CC0. Original license texts are in `licenses/`.
Only the files needed by the game are included, not entire source packs.

Light, particle and audio originals came from `C:\Dev\AssetsShared`.
Game Icons was downloaded from Kenney's official site on 2026-09-28:
https://kenney.nl/media/pages/assets/game-icons/1ebf9c14af-1677661579/kenney_game-icons.zip

Textures are tinted and scaled at runtime; sources are otherwise unmodified.
The interface geometry and puzzle cells are project-authored, using these assets
for ambient light, celebration, sound and navigation. No paid or unclear-license
assets are included. Additional itch.io assets must be free, with explicit
commercial-use permission and their attribution/redistribution terms preserved.
