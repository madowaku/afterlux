## 0. この変更が狙う最小感動体験（MDE）

> 2つの点を並べて1回だけ光を放つと、1本ずつ影が伸びて、重なったマスだけが濃くなり「+2」が浮かぶ。

試遊レポート v0.2 の課題（013・018「1SHOTで濃さ2になる仕組みが理解しにくい」）に直接答える。
説明文を増やすのではなく、**発射の瞬間に原因（点ごとの影）と結果（+2）を同じ場所で見せる**ことを優先した。

## 3. 「光1回で影2段」の視覚表現 — 検討した案

| 案 | 採否 | 理由 |
|---|---|---|
| A. 発射時に**点ごとに影の帯**を時間差で伸ばす。重なると帯が重なって濃くなる | **採用** | 原因（点ごと）と結果（濃さ）が同じ場所で同時に見える。点のマスは帯が途切れ、点線だけ通る＝「影はつかないが先へ進む」も同時に見える |
| B. 影が届いたマスに **+1 → +2** のバッジ。次の操作まで残す | **採用** | 帯の到着ごとに数が増える瞬間を見せ、発射後も「今の1手で何が起きたか」を読める。動きを減らす設定でも静的に表示される |
| C. 各マスの下に**影の層の丸（●○）**。受けた層＝塗り、必要な層＝輪 | **採用** | 「2」を「2つの層」として読ませる。003の「影を2つ重ねよう」と言葉が一致する。超過は赤い丸 |
| D. 影を受けるたびに明るいマスが**一段ずつ暗くなる** | **採用（控えめ）** | 「影が濃くなる」の文字どおりの表現。数字の読みやすさを損なわない範囲（最大30%） |
| E. 発射**前**に影の通り道をプレビュー | **不採用** | 設計方針 v0.2「発射前の影の答えは表示しない」に反する。推理の楽しさを奪う |
| F. 光源の縁の印（盤面の入射辺に金色の山形） | **採用** | 方向だけを示し答えは示さない。v0.2 の「016以降で矢印を誤読しないか → 盤面の縁に光源を置く追加試作」に対応 |
| G. 初めて+2が出た時だけの一回限りのチュートリアル | **代替案を採用** | 保存データの追加が要るため、代わりに「+2以上が出た発射の直後は毎回、金色の一文で名前を付ける」にした |

## 4. 実装したこと

- **影の帯**（`game/board/board_view.gd`）：点ごとに220msで伸び、120msずつ時差。1点≈0.32秒、2点≈0.44秒。動きを減らす設定では0秒。
- **+N バッジ**：帯の到着ごとに増え、発射後もマス左上に残る。+2以上は金色。次に点を置く・一手戻す・やり直すで消える。
- **層の丸と段階的な暗さ**（`game/board/cell_view.gd`）。凡例に「●○ 影の層」を追加。
- **光源の縁の印**：選んだ光が入ってくる辺に金色の山形。クリア後と発射中は消える。
- **重なりの一文**：1SHOTで+2以上が出たら「影が重なりました。1回の光で +2 のマスがあります。…」（日英）。
- **CLEAR／PARのリザルトを分ける**：PARは金色の枠と見出しで「次へ」が主ボタン。PAR超えのCLEARは「最短手に挑む」が主ボタン（ベスト記録は保持）。
- **遊び方**に「03 影を重ねる」を追加（旧03・04は04・05へ）。
- 不具合修正：フォーカス中の主ボタンの文字が背景と同色で読めなかった（`STYLE.accent` に focus 色を追加）。盤面の作り直し直後に描いたバッジが、グリッド再配置後に古い位置に残る問題（`sort_children` で再描画）。
