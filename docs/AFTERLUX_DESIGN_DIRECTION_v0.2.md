# AFTERLUX — 小さなひらめき、深い最短手

2026-09-28 / 初期ブラッシュアップの方向と次の検証

## 今回選んだ軸

**短い問題でひらめき、その同じ問題を最短手まで磨く。**

ユーザーの選好は「ひらめき重視：短い問題＋最短手への挑戦」。
まず解けたことを喜び、そのあと「もう1手減らせそう」が自然に残る体験にする。
速さ・連続ログイン・試行回数では評価しない。

## 独自性を育てる中心

同じ位置にDOTを置いても、まとめて撃つか、分けて撃つかで答えが変わる。

| A1とA2、北からの光 | A1 | A2 | A3 | A4 |
| --- | ---: | ---: | ---: | ---: |
| 同じSHOTでまとめる | 0 | 0 | 2 | 2 |
| 別々のSHOTに分ける | 0 | 1 | 2 | 2 |

DOTは「影を作る」と同時に「そのSHOTでは自分のマスを影から守る」。
この二つの役割が矛盾なく一つの操作に入っている点を主役にする。
007→008の隣り合う問題が、その発見を最小の盤面で示す。
010では3手のクリアを祝ったあと、2手への圧縮を誘う。

これは本作の設計上の特徴であり、他作品に存在しないと調査・証明した主張ではない。

## パズルの育て方

| 候補 | 面白さ | 位置づけ |
| --- | --- | --- |
| **Twins / 双子問題** | ソケットを変えず、目標だけを変える。さっきの解き方が通じなくなる | 最優先。007・008の形式を増やす |
| **One Less / あと1手** | まず普通に解ける。2つのSHOTをまとめると別の穴が現れる | CLEAR→PARの主軸 |
| **Quiet Spaces / ゼロを読む** | 大きな数字より、影を入れられないマスが決め手になる | 中級者の推理の手掛かり |
| **Reverse Layers / 影の分解** | 完成形を2〜4枚の影に分けて考える | 熟練者向けの本筋 |
| **One Use / 一度だけ** | 再使用不可のソケットで順序を考える | 基本系の採掘後に別パックで検討 |

最初の4系統は、鏡・ワープ・遮蔽物を増やさず作れる。
序盤でギミックを足すより、「同じ道具で考え方だけが変わる」問題を優先する。
盤面サイズだけで難易度を上げない。4×4でも十分に難問を作れる。

## 毎日解きたくなる仮説

日替わりモードは今回未実装。まず編集した100問の問題集を実際に遊び、解き味と質を確かめてから進める。

1. **SPARK**：短い導入問題。帰宅中にも1問だけ解ける。
2. **SHIFT**：SPARKと同じソケットを使う対の問題。解き方が反転する。
3. **REFINE**：解けるが最短が難しい問題。余力のある人のための挑戦。

3問すべてを義務にしない。1問のCLEARだけでもその日の体験が完結する。
まず想定する時間はSPARK 1〜2分、SHIFT 2〜5分。プレイテストで修正する仮説であり、実測ではない。
未プレイ分はアーカイブから遊べるようにし、日を逃した罰を作らない。
将来の週末難問は別枠で用意し、日常の短さを壊さない。

記録はCLEARとPARの二段階。総SHOT数や最終解の手数を共有できても、タイマー・Undo回数は優劣の軸にしない。
ネタバレを防ぐ共有カードは問題ID、使用SHOT数、PAR達成の有無までにする。
「毎日違うランダム盤面」をそのまま出すのではなく、意味のある対と発見を編集する。

## パズル好きに応える品質基準

- PARは独立したソルバーで証明する。見つけた解の手数を最短と呼ばない。
- 最短解数はSHOTの順番の違いだけを同一視する。DOT配置や光が違えば別解として数える。
- チュートリアルは最短解の多重集合が1つであることを確認する。
- 中盤以降は「別解がある＝悪問」と決めず、意図した発見があるかで採否を決める。
- 解の有無だけでなく、単独DOT必須・複数DOT必須・方向の種類・圧縮幅・対称重複を記録する。
- 探索ノード数だけを人間の難しさに変換しない。ゼロから確定する一手や、考える分岐の数を調べる。
- 生成器の採用判定に人の試遊を残す。「どこで気づいたか」を言語化できる問題を選ぶ。
- 将来のヒントは「A1に置く」より、「この0のマスを守るには？」のように観察を促す。

## UI / UXの方針

夜の光学器具を思わせる深い青緑、温かな白、淡いミント。
必要な数字が残るマスは明るく、完成したマスは静かに沈む。
色だけに依存せず、残数、負数、チェック印、DOTの輪郭でも状態を区別する。
光ボタンは「光源の位置」と「影の進む矢印」を併記する。Nの矢印は下向き。

今回の実装：

- 100問・12章のセレクター。最初の4章は導入各5問、次の7章はテーマ別に各10問、最後の章に総合問題10問。
- 700問の生成候補からGPT-6 Astra / xhighが80問を選定。選定記録と理由を保存し、100問すべてのPARと一意な最短解を独立ソルバーで検証。
- 4×4 / 5×5の盤面。選択したDOTのあるマスでも残数を隠さない。
- 180msの発射演出、着地した影の反応、PAR/CLEARを分けたリザルト。
- 無制限Undo、進行中のリスタート確認、クリア後の即リトライ。
- 問題ごとの途中状態、ベスト、直前の問題、音とモーション設定の保存。
- キーボードフォーカス、消音、動きを減らす設定。
- KenneyのLight Masks / Particle Pack / UI Audio / Game Iconsを使用。
- 発射前の影の答えは表示しない。結果を読む行為を残す。

日本語・英語を遊び方／設定から即時に切り替えられる。
盤面、途中の手順、選択中の点と光の向き、ベスト記録を維持し、言語の選択を保存する。
初回は端末の言語が日本語なら日本語、それ以外は英語。
Noto Sans JPをOFLライセンス付きで同梱し、端末のフォントに依存せず日本語を描画する。

## 次に試遊で確かめること

| 観察 | 次の判断 |
| --- | --- |
| 001を説明なしで操作できるか | DOTの誘導、光源の表示、初回の案内量 |
| 007→008で違いを自分の言葉で説明できるか | 対の配置と説明タイミング |
| 010の3手クリア後に2手へ挑みたくなるか | リザルトの文言と再挑戦の導線 |
| Undoを使って気持ちよく仮説を試せるか | 発射テンポと履歴表示の必要性 |
| 016以降で矢印を誤読しないか | 盤面の縁に光源を置く追加試作 |
| 5×5のソケット残数を実機で読めるか | 数字サイズ、コントラスト、片手操作 |

次の実装候補は、日替わり機能そのものより**双子問題と「CLEAR→PAR」の手応えを人の試遊で確かめること**。
この100問を日付で循環させるだけの仕組みは、新しい日替わり問題として扱わない。
